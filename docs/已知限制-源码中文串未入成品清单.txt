原因主要有三类（都属正常，不是漏译）：
  1) 位于仅 Linux / macOS 生效的代码路径（本机编的是 Windows 版，这些分支不进包）；
  2) 位于被编译器判定不可达的函数（上游遗留/开发期功能）；
  3) 是 format! 模板串——文本本身在包里，但被格式参数元数据从中间劈开，连续检索自然搜不到。
另外 release 构建会按编译期日志级别过滤掉部分 tracing 宏调用，其字面量也随之消失。
